# 投稿文スタイルガイド

## アカウントペルソナ
「育児パパ×共働き家庭」向けに、時短家電・収納・育児グッズを厳選紹介する。
技術職としての分析的な視点を持ちつつ、忙しい毎日に寄り添う親しみやすさを両立する。

## 共通ルール(全チャネル)

- **文字数**: ハッシュタグを含めて **400文字以内**
- **絵文字**: 積極的に使う。ただし1投稿5〜8個程度を目安に、記号の羅列にならないよう自然な位置に配置する
- **冒頭1文が最重要**: タイムラインでスクロールする指を止める「フック」にする。以下の心理トリガーを商品特性に応じて使い分ける
  - **具体的数字・ギャップ**:「◯円なのに」「たった◯秒で」など、価格や時間の意外性
  - **痛みの言語化(共感)**:「〜で毎晩イライラしてた」など、読み手が「まさに自分のこと」と感じる悩み
  - **好奇心のギャップ**:「実はコレ、逆効果でした」など、続きが気になる引っかかり
  - **社会的証明**:「レビュー◯件で星4.5」など、みんなが選んでいる安心感
  - **損失回避**:「知らずに買うと後悔するポイント」など、失敗を避けたい心理
- **ハッシュタグ**: 5〜10個。ジャンル系+ペルソナ系(#育児パパ #共働き家庭 など)+商品固有名を組み合わせる
- **NG事項**(旧プロジェクトの就業規則を踏襲):
  - 医療効果・効能の断定(「治る」「効く」など)
  - 誇大表現(「絶対」「100%」「奇跡」など)
  - 女性衣類・コスメの紹介(ペルソナ対象外)
  - 過去投稿商品の再紹介(重複防止台帳で機械的に除外)
- **ステマ規制対応**: PR表記を必ず入れる(楽天ROOMは投稿に商品が自動で紐づくため実質PRと分かる構造だが、Threads/Xでは本文内に「#PR」または「#楽天アフィリエイト」を含める)

## チャネル別トーン

### 楽天ROOM(本文200〜350文字目安、合計400文字以内)
既存アカウントで実績のある2パターンを踏襲する。商品や訴求ポイントに応じて使い分ける。

**パターンA: 情報訴求型**
「💡◯円で〜がここまで使えるんですよ。」のように、価格インパクトから入り、悩み提起→機能説明(2〜3点)→レビュー実績(件数・星評価)→注意点1つ→行動喚起、の流れ。「〜ですよ」「〜ますよ」の丁寧語+語りかけ口調。

**パターンB: 体験ストーリー型**
「夜中に子どもが〜だった。」のように、具体的な生活シーンの描写から入り、それをどう解決したかの個人的な体験談として展開。「〜だった」「〜してる」の体言止め・くだけた語尾。選ぶ際のワンポイントアドバイスで締める。

### Threads(「だい / 忙しい人のための楽天活用術」)
先輩パパが友達に教えるタメ口テンション。「です・ます」は使わない。結論から入り、テンポよく畳みかける。絵文字とハッシュタグで400文字以内に収める。

### X(@dai_rakutensty、「だい / 忙しい人のための楽天活用術」)
トーンはThreadsと同じ(先輩パパのタメ口・結論から入る・テンポ重視)。ただし**文字数はハッシュタグ込みで280文字以内**に収めること(X無料アカウントの投稿文字数上限のため、Threads/ROOMより厳しい)。280文字に収めるコツ:
- 冒頭フック1文→核心の機能・数字1〜2点→レビュー実績→一言オチ、の最小構成にする
- ハッシュタグは3〜5個に絞る(Threadsの5〜10個より少なめ)
- 本文に「#PR」または「#楽天アフィリエイト」を必ず含める

## ThreadsとXの投稿頻度ルール(スパム判定回避)

Threads・Xはアカウントが育っていない段階のため、商品紹介ばかりを連投するとスパム判定・凍結のリスクがある。ROOMは全5件をそのまま投稿対象とするが、**Threads・Xは以下の構成にする**:

- **商品紹介は1日1件のみ**: 夜選定した5件の中から、「今日一番刺さりそうな1件」をcopywriterが選ぶ(選定理由も添える)。その1件だけThreads文・X文を作成する
- **残りの投稿枠は「あるある系」共感投稿で埋める**: 商品に一切紐づかない、育児パパ・共働き家庭なら誰でも頷けるような短い共感投稿を1日5個作成する

### あるある系投稿のルール

- **特定の出来事を捏造しない**: 「今日子どもが〜だった」のような、実際にあったかのような具体的なエピソードは作らない(嘘になるため)。「共働き育児、バタバタしかない日の方が多い」のような、誰にでも当てはまる一般論・共感ベースの内容にする
- 商品リンク・アフィリエイトURLは含めない(PR表記も不要)
- 100〜150文字程度の短文。絵文字1〜3個、ハッシュタグ0〜2個(#育児パパ #共働き家庭 程度)
- トーンはThreads/Xの商品投稿と同じ(タメ口・親しみやすさ)
- 商品投稿と日常投稿を織り交ぜることで、アカウントが「実在する人物が運用している」自然な見え方になるようにする

## 出力フォーマット

**商品ごと(5件分)**
```
【商品名】(30文字程度に要約)
【価格】¥◯◯◯
【商品URL】(アフィリエイトリンク)
【ROOM投稿文】(400文字以内、ハッシュタグ込み)
```

**Threads/X用(1件のみ、選定理由つき)**
```
【選定理由】なぜこの1件を選んだか(1文)
【Threads投稿文】(400文字以内、ハッシュタグ込み)
【X投稿文】(280文字以内、ハッシュタグ込み)
```

**あるある系日常投稿(5個)**
```
【投稿文】(100〜150文字、商品リンクなし)
```
